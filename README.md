# Follow-up Management System

A full-stack web application designed to help healthcare facilities manage patient follow-up communications efficiently.

## Features
- Manage patient follow-up requests
- View and process follow-up queues
- Generate department-specific email communications
- Track follow-up activity

## Technologies
- Java and Spring Boot
- JavaScript, HTML, CSS
- MySQL
- Maven
- Git and GitHub

## Project Purpose
Developed as a software engineering capstone project to address inefficiencies in managing patient follow-up communications across healthcare departments.
